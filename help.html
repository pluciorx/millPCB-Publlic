millpcb.com — Help & Reference

Browser-based PCB editor with laser cutter export. No install, no server — runs entirely in your browser.

Views

Board View (default)

Top-down view of the PCB in millimeters. Shows copper traces, component footprints, vias, board outline, and silk screen annotations. Supports pan, zoom, and rotation.

Schematic View

Electrical wiring diagram with type-specific symbols (resistor zigzag, IC boxes, LED triangles, etc.). Wires drawn here create actual board traces. Components can be dragged to arrange the schematic layout independently of their board positions.

Switch: Use the “Board” / “Schematic” buttons in the toolbar.

Component Placement

  1. Click a component in the left palette (or click ▾ to choose a package size)
  2. A ghost preview follows the cursor on the board — it snaps to the grid and magnetically aligns with edges/centres of existing components
  3. Press R or Space to rotate the ghost before placing
  4. Left-click to place the component (it lands exactly where the ghost was shown)
  5. Repeat for multiple placements (palette item stays active until Escape or another tool is selected)
Tip: Selecting a size from the dropdown immediately arms placement — no second click needed.

Alignment guides: While placing or moving a single part, magenta guide lines appear when one of its edges or centres is close to another component's edge or centre — the part snaps to that line.

Rulers: mm rulers run along the top and left canvas edges and follow pan/zoom (tick density adapts to zoom). Click Rulers in the status bar to hide or show them.

Jumpers (JP): JP wire is placed with two clicks, like drawing a trace: each click snaps magnetically to an existing pad, via or trace end (grid otherwise), so you can just click pad A → pad B. The rubber-band ghost shows the span; second click commits the pair of solder holes (drilled pads). Spans shorter than the pad clearance are rejected — click farther away. The wire jumper has no copper between the holes (you solder the wire on); select it and edit Span in the properties panel to resize after placement.

Multi-select: Drag a box around parts, or hold Ctrl/Shift and click. Right-click → Group (or Ctrl+G). Click any grouped part to move them together. Ctrl+Shift+G ungroups. Deleting a part leaves its traces on the board.

Trace Drawing & Editing

  1. Select the Trace tool
  2. Click to place waypoints (snaps to grid and nearby pins)
  3. The active trace follows the cursor as a rubber-band line
  4. Double-click or right-click to finish the trace
  5. Esc to cancel the current trace

Editing Existing Traces

  • Click a segment to select it (cyan highlight). Drag a horizontal segment up/down, or a vertical segment left/right — connected corners stretch and pads stay connected
  • Click a vertex to drag that corner
  • Double-click a segment to insert a vertex
  • Delete a joint: select a vertex and press Del, or right-click → Delete Joint. The trace re-routes automatically — removing a joint never deletes the whole trace (joints sitting on pads are protected).
  • Delete several joints at once: hold Ctrl/Shift and click multiple joints, then press Del (or right-click → Delete N Joints) to remove them all in a single undo step.
  • Select a segment → change width in the properties panel
  • Each segment can have an independent width (clamped by pad constraints at endpoints)

Curved Traces

Segments can be toggled to render as quadratic Bézier curves. The control point is automatically computed for a smooth arc between the two endpoints.

Schematic Wiring

  1. Switch to Schematic view
  2. Click a pin on one component → a rubber-band wire follows the cursor
  3. Click a pin on another component to complete the wire
  4. A board trace is automatically created connecting those pins’ physical positions
  5. If both pins are already on the same net, the new trace joins that net
  6. If pins are on different nets, you are prompted to merge or create a new net

Net Management

  • Nets are named electrical connections (VCC, GND, SIG1, NET_4, …)
  • Each net has a unique color used for rendering traces and wires
  • Add custom nets via the properties panel “Add Net” button
  • Assign traces to nets in the trace properties panel
  • Schematic wiring automatically assigns/merges nets

DRC (Design Rule Check)

Click the DRC button to run all checks. Results appear in a panel:

  • ✓ Pass (green) — no violations
  • ✗ Fail (red) — errors and warnings listed with descriptions

Configurable parameters (in left panel):

  • Minimum trace width (mm)
  • Minimum drill diameter (mm)
  • Minimum clearance between nets (mm)

Export

FormatButtonDescription
SVGExport SVGVector graphic with CSS classes for laser cutting. Includes outline, traces, holes, component outlines.
DXFExport DXFAutoCAD R2000 interchange file with named layers. Traces are centerlines (not toolpaths). Opens the Export Settings dialog — choose Standard (LWPOLYLINE) or Legacy (POLYLINE/VERTEX), and optionally mirror X for a backside view.
G-codeExport G-codeGRBL: isolate copper (offset by tool radius), drill holes, then cut the board outline. Origin is the south-west corner. Opens the Export Settings dialog; mirrored output is marked with a comment in the file.

Export options are configured in the Export Settings dialog (opened by Export DXF / Export G-code):

  • Kerf width compensation (mm)
  • Unit system (mm / inches)
  • DXF format (R2000 Standard or R2000 Legacy)
  • Toggle inclusion of outline, copper outlines, holes, traces, components
  • Mirror X — backside view for milling the other layer
  • Preview — toolbar button or toggle in the modal header shows a live SVG of the DXF entities with a color legend, updated as you change settings
  • Layers — choose which DXF layers to include: COPPER_TOP / COPPER_BOTTOM (merged milling outlines of traces + pads + vias), TRACE_OUTLINE_* (trace boundaries), TRACE_* (centerlines, reference only) and PAD_* (pads and via rings). For G-code the bottom isolation section is milled after flipping the board over.
  • CNC mill: tool diameter, isolation depth, safe Z, feed, plunge, spindle

KiCad Import

Import footprints and symbols from KiCad v5/v6 files:

  1. Click “Import KiCad” button (or drop files)
  2. Supported inputs:
    • Single .kicad_mod file (footprint)
    • Single .kicad_sym file (symbol library)
    • .zip archive containing a full KiCad footprint/symbol package
  3. Imported parts appear in the component palette
  4. Custom definitions are saved with the project (importedDefs field)
Note: The app must be served over HTTP (not file://) for KiCad library auto-loading to work. Use npm run server or any static file server.

Component Rotation & Traces

When you rotate a component (via R, Space, middle-click, or the properties panel), all connected traces automatically follow the pins to their new positions. This ensures your design stays electrically valid after rotation.
