Official development-board footprints vendored for millPCB (CC-BY-SA 4.0 KiCad libraries unless noted).

- Arduino Uno R3, Arduino Nano, Arduino Nano ESP32, Wemos D1 mini, Wemos S2 mini, Raspberry Pi Pico:
  KiCad Footprint Libraries (https://gitlab.com/kicad/libraries/kicad-footprints).
- ESP32-DevKitC, ESP32-S3-DevKitC, ESP32-S2-DevKitC-1:
  Espressif KiCad Libraries (https://github.com/espressif/kicad-libraries), Apache License 2.0.

Passive / IC / transistor packages under `libs/` are from the same KiCad footprint libraries (Package_DIP, Resistor_SMD, Device, etc.).
